# 巨量引擎信息流广告优化器（浏览器模式）

## 概述

通过浏览器自动化操作巨量引擎后台，实现投放全流程自动化。
无需 API，只需浏览器登录态。

- **单粉成本** (CPF) < RMB 0.17
- **单互动成本** (CPE) < RMB 0.009
- 自动化运维: 建新广告 -> 关停劣质 -> 复盘 -> 学习 -> 实验 -> 循环

## 前置配置

### 登录态

首次使用时，确认用户已登录巨量引擎：
1. 打开 `https://ad.oceanengine.com/` 或 `https://qianchuan.jinritemai.com/`
2. 确认已进入广告管理后台（能看到广告列表）
3. 截图确认当前账户名称和余额

> 登录态由系统浏览器维护，技能不存储用户名密码。

### 账户识别

首次使用确认以下信息：
- 使用的账户名称 / ID
- 当前余额
- 目标：涨粉 / 互动（默认：以涨粉为主，CPF < 0.17）

## 核心能力

### 1. 账户监控

**查余额** -- 每次操作前执行：
- 导航到巨量引擎首页 `https://ad.oceanengine.com/`
- 查看页面顶部或账户信息区的余额
- 也可以进入「账户中心 -> 财务 -> 资金管理」确认

预警规则:
- 余额 < 3 天日均消耗 x 1.5 -> [警告] 提示用户充值
- 余额 < 2 天日均消耗 -> [紧急] 警告 + 暂停新建
- 余额 < 200 元 -> 不再新建广告，仅维护现有

### 2. 每日广告管理

**查看广告列表:**
- 进入「推广管理」页面
- 截图获取所有「投放中」的广告列表
- 记录每条广告: 名称、预算、状态、消耗、展现、点击、粉丝、互动、成本保障状态

**获取昨日报表:**
- 进入「报表」页面
- 设置日期范围为昨日
- 导出或截图报表数据
- 提取关键指标: 消耗、CPF、CPE、CTR

**关停低效广告** -- 先看赔付状态，再决定停不停:

> 平台有成本保障（赔付）机制：转化成本超出价的 20% 以上，且保障期内转化数达标，平台把超出部分以赠款赔付。**能赔的广告不要停，跑满保障期反而划算。**

第一步 -- 读广告列表里的「成本保障」状态列:
- `成本保障生效中` -> 走赔付保护逻辑
- `成本保障确认中` -> 不动，等系统核算
- `已失效 / 已结束 / 已到账` 或 已过 3 个自然日 -> 走硬红线

第二步 -- 赔付保护逻辑（状态为生效中）:
- 超成本 >= 20% **且** 预计 3 天转化数 >= 6 个 -> **不停，跑满等赔付**
- 超成本 >= 20% **但** 转化数明显到不了 6 个 -> 可停，够不到赔付门槛
- 超标但没到赔付线（0.17 < CPF < 出价 x 1.2）-> 量好留着观察 2 天，量差就停
- 消耗 > 150 元 **且** 新增粉丝 = 0 -> 停（没转化数就没有赔付）
- CTR < 0.8% **且** 展现 > 10000 -> 停（素材硬伤）

第三步 -- 硬红线（无赔付兜底，触发即停）:
- 消耗 > 100 元 **且** CPF > 0.17 -> 关停
- 消耗 > 50 元 **且** CPE > 0.009 -> 关停
- 连续 3 天 CPF 持续上涨 -> 降预算 50%

赔付期禁忌（做了赔付作废）: 每天改出价或定向各不超过 2 次、保障期内不要暂停、不要开一键起量。
完整规则与算账方法见 `references/optimization_rules.md`。

关停操作: 在广告列表中找到对应广告，点击「暂停」按钮。

**创建新广告** -- 看消耗速度决定建几条:

先算消耗率 = 近 3 天日均消耗 / 账户日预算总额
- 消耗快（>= 85%）-> 基本不建，改成给跑得好的老计划加预算
- 消耗中（50%-85%）-> 正常建
- 消耗慢（< 50%）-> 必须建，现有广告跑不动了

| 余额 | 消耗快 | 消耗中 | 消耗慢 |
|------|--------|--------|--------|
| > 1000 | 0-1 条 | 3-5 条 | 5-6 条 |
| 500-1000 | 0-1 条 | 2-3 条 | 3-4 条 |
| 200-500 | 0-1 条 | 1-2 条 | 2-3 条 |
| < 200 | 0-1 条 | 1 条 | 1-2 条 |

余额低于 200 也要建，只是建得少。单条预算最低 50 元，所以余额少时最多 2 条。

创建流程（浏览器操作）:
1. 点击「新建广告」-> 选择「信息流广告」
2. 设置推广目标（吸粉选「账号关注」，互动选「互动量」）
3. 填写广告组: 名称、日预算、投放时段
4. 设置定向: 按 `references/optimization_rules.md` 中「新建广告组合策略」
5. 设置出价: 参考目标 CPF x 1.3
6. 上传素材 / 撰写文案
7. 提交审核

素材轮换: 干货型 -> 情感型 -> 悬念型 -> 热点型

**加量决策:**
- CPF < 0.10 且接近日预算 -> 调整预算 x1.5 (上限 5000)
- CPE < 0.005 持续 2 天 -> 调整预算 x1.5
- CTR > 5% -> 考虑复制广告组

### 浏览器操作关键原则

- 每次操作前先截图确认当前页面
- 点击按钮/链接前确保元素可见
- 提交前二次确认内容无误
- 遇到弹窗/验证码 -> 立刻截图告知用户
- 操作间隔 2-3 秒，避免触发反爬

## 注意事项

- 浏览器操作速度不要过快，间隔 2 秒以上
- 遇到验证码或滑块验证 -> 暂停操作，截图告知用户
- 平台可能会弹出活动/公告窗口 -> 先关闭弹窗再继续
- 所有关停操作前二次确认 CPF/CPE 计算无误
- **关停前必看「成本保障」状态，赔付生效中的超成本广告不要停**
- **赔付期内的广告不要改出价、不要改定向（每天各不超过 2 次），否则赔付失效**
- **不要为了拿赔付刻意抬高成本，赠款超过实付现金 50% 会触发平台风控，可能被拒付或追回**
- 新建广告提交前让用户确认定向和预算
- 策略学习结果需人工审核后再纳入正式投放
