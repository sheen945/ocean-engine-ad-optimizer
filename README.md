# ocean-engine-ad-optimizer

> 巨量引擎信息流广告智能优化技能（浏览器模式）——无需 API，通过浏览器自动化完成投流全流程：建新广告、关停低效、监控余额、每日复盘、策略学习与实验验证。

## 简介

这是一个面向 WorkBuddy / Claude Code 的 Agent 技能（Skill）。它让 AI 助手通过浏览器自动化登录巨量引擎（Ocean Engine）广告后台，代替人工完成信息流广告的日常运维：每天检查账户余额、拉取昨日报表、按成本红线关停劣质广告、按消耗速度决定新建数量、输出复盘日报，并持续从官方与行业渠道学习最新投流方法论、用小预算实验验证。

适用于无法申请到巨量引擎 Marketing API、但拥有后台登录权限的个人投手、自媒体运营者和中小商家。核心优化目标：**单粉成本（CPF）< ¥0.17，单互动成本（CPE）< ¥0.009**。

**触发关键词**：巨量引擎、信息流广告、投流、涨粉、吸粉、千川、CPF、CPE、广告优化、投放优化、ocean engine、巨量广告。

## 功能特性

- **账户余额监控与预警**：每次操作前自动查余额；余额低于 3 天日均消耗 ×1.5 时警告，低于 2 天日均消耗时紧急告警并暂停新建，低于 ¥200 时仅维护现有广告。
- **成本保障（赔付）感知的关停决策**：关停前先读「成本保障」状态列——保障生效中的超成本广告不轻易停（跑满保障期等平台赔付更划算），保障期已过的广告走硬红线（消耗 >¥100 且 CPF>0.17 立即关停等），避免误杀可获赔的计划。
- **智能新建广告**：根据近 3 天消耗率（快/中/慢）和账户余额四档对照表决定每日新建条数（0–6 条），并通过浏览器完成定向、出价（目标 CPF ×1.3）、素材上传、提交审核全流程。
- **加量与预算调整**：CPF < 0.10 且接近日预算时预算 ×1.5（上限 5000），CTR > 5% 时考虑复制广告组，让跑量好的计划充分放量。
- **每日复盘日报**：内置标准化日报模板，输出消耗/CPF/CPE/CTR、赔付到账、广告操作明细、余额可支撑天数与趋势分析。
- **策略学习与实验闭环**：`scripts/strategy_scraper.py` 从巨量引擎官方帮助中心、巨量学、36氪、鸟哥笔记等来源抓取最新方法论，标注可信度并推荐实验方案；实验采用「对照组 + 3 天 / ¥200 观察期 + CPF 低 15% 才转正」的严谨框架。
- **指标自动计算**：`scripts/ad_operations.py` 根据消耗、展现、点击、粉丝、互动数据自动计算 CPF/CPE/CTR，并给出暂停/加量建议。

## 工作原理 / 技术栈

- **载体**：WorkBuddy / Claude Code Agent Skill（`SKILL.md` 声明式技能定义 + references + scripts）。
- **浏览器自动化**：所有网页操作通过 `chrome-browser` 技能完成（Google Chrome + CDP 调试端口 9222 + 固定登录态目录 `chrome-cdp-profile`）。登录态由系统浏览器维护，技能不存储用户名密码。
- **脚本**：Python 3 标准库实现（`urllib`、`json`、`re`），无第三方依赖。
- **规则文档**：`references/optimization_rules.md` 存放完整成本红线与赔付算账方法；`references/web_guide.md` 存放巨量后台各页面的导航路径。

每日执行流程：

```
1. 查余额 -> 不足则告警 + 跳过新建
2. 进入推广管理 -> 截图活跃广告列表
3. 进入报表 -> 取昨日各广告数据
4. 按关停规则逐条检查 -> 暂停不达标者（先看赔付状态）
5. 按余额与消耗速度决定新建数量 -> 浏览器逐条创建
6. 运行策略学习脚本
7. 输出复盘日报
8. 汇总操作结果与异常给用户
```

## 安装与使用

把本仓库目录复制到技能目录，文件夹名保持 `ocean-engine-ad-optimizer`：

- WorkBuddy / CodeBuddy：`~/.workbuddy/skills/ocean-engine-ad-optimizer/`
- Claude Code：`~/.claude/skills/ocean-engine-ad-optimizer/`

重启会话后，通过触发关键词（如「巨量引擎」「投流」「CPF」）即可自动匹配启用。

**首次使用前置条件**：

1. 在系统 Chrome 浏览器中登录 `https://ad.oceanengine.com/` 或 `https://qianchuan.jinritemai.com/`，确认能进入广告管理后台。
2. 确认账户名称/ID、当前余额与投放目标（涨粉 / 互动，默认涨粉 CPF < 0.17）。

策略学习脚本可单独运行：

```bash
python scripts/strategy_scraper.py
```

## 注意事项

- 依赖本机已安装 `chrome-browser` 技能；浏览器操作间隔保持 2 秒以上，避免触发反爬。
- 遇到验证码 / 滑块 / 弹窗时立即暂停并截图告知用户，不擅自处理。
- **赔付期内的广告不要改出价、不要改定向（每天各不超过 2 次），不要暂停、不要开一键起量，否则赔付作废。**
- 不要为拿赔付刻意抬高成本——赠款超过实付现金 50% 会触发平台风控。
- 新建广告提交前需用户确认定向与预算；策略学习结果需人工审核后再纳入正式投放。
- 技能不存储账号密码，登录态完全由本机浏览器维护。
