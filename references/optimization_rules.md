# 巨量引擎信息流投放优化规则

## 核心成本线

| 指标 | 计算方式 | 红线 | 理想线 |
|------|----------|------|--------|
| 单粉成本 (CPF) | 消耗 / 新增粉丝 | ≥0.17 → 立即关停 | ≤0.12 |
| 单互动成本 (CPE) | 消耗 / (点赞+评论+分享) | ≥0.009 → 关停 | ≤0.006 |
| 点击率 (CTR) | 点击 / 展现 | <1.5% → 素材不合格 | ≥3% |
| 转化率 (CVR) | 转化 / 点击 | 视行业浮动 | 持续优化 |

## 广告生命周期管理

### 新建广告判定窗口
- 新广告观察期: 消耗达到 50 元 或 展现达到 5000 次（先到为准）
- 观察期内不做关停决策，仅记录数据

### 关停规则 (每日自动执行)

**核心原则：能拿到平台赔付的超成本广告，不要停，让它跑满保障期。**

关停前先分两类：「成本保障期内的广告」和「保障期已过的广告」，两套标准完全不同。

---

#### 第 0 步：看赔付状态（计划列表有「成本保障」状态列）

| 状态 | 走哪套规则 |
|------|-----------|
| 成本保障生效中 | A 类（赔付保护逻辑） |
| 成本保障确认中 | 不动，等系统核算结果 |
| 已失效 / 已结束 / 已到账 | B 类（正常红线，无赔付兜底） |
| 超过首次投放 3 个自然日 | B 类（保障期已过） |

---

#### A 类：处于成本保障期（赔付保护逻辑）

先算两个数：
```
超成本比例 = (实际 CPF - 该计划出价) / 该计划出价 × 100%
预计 3 天转化数 = 当前转化数 ÷ 已投放天数 × 3
```

**判断顺序：**

```
1. 超成本 >= 20%  且  预计 3 天转化数 >= 6 个
   → 绝对不停！跑满保障期等赔付
   （赔付后等效成本 = 出价，比硬亏强得多）

2. 超成本 >= 20%  但  预计 3 天转化数 < 6 个
   → 可停。够不到赔付门槛，赔不到钱，纯亏

3. 0.17 < CPF < 出价×1.2（超标但没够赔付线）
   - 量好（日消耗 >= 预算 60%）→ 留着观察，最多再看 2 天
   - 量差（日消耗 <  预算 30%）→ 停
   - 观察 2 天后超成本比例仍不上升 → 停（够不到赔付线就是实亏）

4. 消耗 > 150 元  且  粉丝 = 0 → 停（没转化数就没有赔付）

5. CTR < 0.8%  且  展现 > 10000 → 停（素材硬伤，赔回来也不划算）
```

**A 类期间的绝对禁忌（做了赔付直接作废）：**

| 禁忌操作 | 后果 |
|----------|------|
| 每天改出价 > 2 次 | 成本保障失效 |
| 每天改定向 > 2 次 | 成本保障失效 |
| 保障期内暂停计划 | 可能拿不到赔付 |
| 开「一键起量 / 账户优选起量」 | 该部分消耗不计入赔付 |
| 用 ROI 出价 / 每次付费 / 自动出价 / 最大转化 | 不适用赔付规则 |

---

#### B 类：保障期已过 或 赔付已失效（硬红线）

没有赔付兜底，超成本就是真金白银的亏损，直接按红线砍：
```
1. 消耗 > 100 元 AND CPF > 0.17    → 停
2. 消耗 > 50 元  AND CPE > 0.009   → 停
3. 消耗 > 150 元 AND 粉丝 = 0       → 停
4. CTR < 0.8%  AND 展现 > 10000    → 停
5. 连续 3 天 CPF 持续上涨           → 降预算 50%，再观察 1 天
```

---

#### 赔付账怎么算（决定值不值得等）

```
预期消耗 = 出价 × 转化数
赔付金额 = 实际消耗 - 预期消耗
等效 CPF = (实际消耗 - 赔付金额) / 转化数 = 出价
```

**实例演算：**
```
出价 0.22，保障期 3 天消耗 300 元，涨粉 1000 个
实际 CPF = 300 / 1000 = 0.30（超成本 36%，触发赔付）
赔付金额 = 300 - 0.22 × 1000 = 300 - 220 = 80 元
等效成本 = 220 元 / 1000 粉 = 0.22 元/粉

对比：
  现在停     → 实亏，0.30 元/粉，且 300 元现金没了
  跑满等赔付 → 0.22 元/粉，还收回 80 元赠款继续投
结论：跑满等赔付明显更划算
```

**赔付的三条硬约束（必须记住）：**
1. 赔付是**减损不是赚钱**——赔完等效成本 = 出价，不是 0.17 目标线，仍然偏贵
2. 赔付以**赠款**形式发放，只能用于后续投放，不能提现，有效期 1 年
3. **风控红线**：累计获得的赔付赠款超过实际支付现金服务费的 50%，或与行业均值严重偏离，平台有权暂停发放、拒发甚至追回。**不要刻意刷赔付**

### 加量规则
```
1. CPF < 0.10 AND 消耗接近日预算 → 日预算 x1.5（上限 5000）
2. CPE < 0.005 AND 持续 2 天 → 日预算 x1.5
3. CTR > 5% → 可考虑复制广告组扩大覆盖面
```

## 每日新建广告策略

### 每日新建数量（消耗速度优先，余额只决定上限）

**先判断消耗速度，再决定建不建。余额少也要建，只是建得少。**

```
消耗率 = 近 3 天日均消耗 / 账户当前日预算总额

消耗快：消耗率 >= 85%（预算基本花完，甚至提前撞预算）
消耗中：50% <= 消耗率 < 85%
消耗慢：消耗率 < 50%（跑不动，钱花不出去）
```

**决策矩阵（每日新建条数）：**

| 账户余额 | 消耗快 ≥85% | 消耗中 50-85% | 消耗慢 <50% |
|----------|------------|--------------|------------|
| > 1000   | 0-1 条 | 3-5 条 | 5-6 条 |
| 500-1000 | 0-1 条 | 2-3 条 | 3-4 条 |
| 200-500  | 0-1 条 | 1-2 条 | 2-3 条 |
| < 200    | 0-1 条 | 1 条 | 1-2 条 |

**为什么消耗快反而少建：**
- 预算就那么多，新计划要重新过学习期，会去抢老计划的量，结果新老都跑不好
- 消耗快说明现有计划跑量能力强，正确做法是**给跑得好的老计划加预算**，比新建稳
- 余额 < 200 且消耗快：钱少还烧得快，先别乱建，只留 1 条试新素材就够了

**硬约束：**
- 单条日预算最低 50 元，最高 300 元
- 余额 < 200 时最多建 2 条（再分散就跑不出量了）
- 消耗慢是危险信号：说明出价低了或素材疲了，优先提价 20% 或换素材，光靠新建解决不了

**消耗慢时的排查顺序：**
```
1. 出价是否偏低    → 24 小时没消耗，提价 20%
2. 素材是否疲劳    → 同一素材跑超 7 天，换素材
3. 定向是否过窄    → 展现量都起不来，放宽定向
4. 是否在赔付期内  → 别乱动，等赔付结算完再调
```

### 新建广告组合策略 (吸粉型)
```
素材维度:
  素材1: 干货/教程型 - 提供有价值信息，评论区引导关注
  素材2: 情感共鸣型 - 引发共鸣，自然涨粉
  素材3: 悬念/互动型 - 提出问题/挑战，评论互动转化粉
  素材4: 行业热点型 - 紧跟当下话题，蹭流量涨粉

定向维度:
  定向1: 兴趣行为词精准匹配 (核心兴趣)
  定向2: 竞品账号粉丝人群 (相似人群扩展)
  定向3: 宽泛行业兴趣 + 排除已转化
  定向4: Lookalike 人群 (基于已有粉丝)

预算分配:
  每个新建广告初始日预算 = 账户日预算剩余 / 新建数量
  最低 50 元/条，最高 300 元/条
```

### 出价策略 (吸粉场景)

**出价方式必须选对，否则不适用赔付：**
- 必须用「控成本投放」+ oCPM
- 不能用：自动出价、最大转化投放、ROI 出价、每次付费出价、投放管家、RTA 直接出价

**出价金额怎么定（赔付视角）：**

赔付把等效成本拉回到「出价」，所以出价越贴近 0.17 目标线，赔付后越接近目标。但出价太低会跑不出量，所以分两档：

```
保量档：出价 = 0.17 × 1.3 ≈ 0.22
  适合：新账户、新素材冷启动、消耗慢时
  特点：容易跑出量，赔付线 0.264，赔完等效 0.22

压价档：出价 = 0.17 × 1.1 ≈ 0.19
  适合：账户已有数据积累、消耗快时
  特点：赔付线 0.228，触发赔付更容易，赔完等效 0.19
  风险：可能跑不出量

建议比例：消耗慢时保量档占 70%，消耗快时压价档占 50%
```

**动态调整：**
- 24 小时没消耗 → 提价 20%
- 跑量很快但 CPF 高 → 降价 15%
- **但处于赔付保障期内的计划，改出价每天不超过 2 次，否则赔付失效**
- 拿不准时：宁可等保障期（3 个自然日）结束再调，别为了省几块钱丢了赔付

## 时间维度优化

### 时段分析
- 每小时取报表，找出粉丝转化高峰时段
- 预算倾斜到高效时段
- 低效时段（凌晨 2-6 点）降低出价或暂停

### 每周节奏
- 周一至周五: 工作日策略
- 周末: 可能转化率不同，需单独观察
- 节假日: 竞争激烈，CPM 通常更高

## 素材优化

### 素材淘汰规则
- 使用超过 7 天且 CTR 持续下降 → 替换
- 消耗 > 500 元但 CPF > 0.20 → 淘汰
- 同一素材多个广告均表现差 → 素材问题，全局替换

### 素材测试框架
```
A/B 测试: 
  变量1 封面图 A vs B (其他一致)
  变量2 文案风格 A vs B (其他一致)
  变量3 定向人群 A vs B (同一素材)
  
  每个变量测试: 至少 200 元消耗或 3 天
  胜出标准: CPF 低 15% 以上且统计显著
```

## 预算管理

### 账户预算安全线
- 预警线: 余额 < 3 天日均消耗 × 1.5
- 告急线: 余额 < 2 天日均消耗
- 立即通知用户充值的触发条件

### 每日预算分配公式
```
总可用预算 = min(账户余额, 账户日预算)
单广告预算池 = 总可用预算 * 0.7 / 活跃广告数  (70% 稳定投放)
测试预算池 = 总可用预算 * 0.3                  (30% 新广告测试)
```

## 精准粉丝优化

### 精准度提升手段
1. 兴趣行为词: 使用 3-5 级细分词，避免泛词
2. 排除已关注人群
3. 排除不精准年龄/地域
4. 根据已有粉丝画像反向优化定向
5. 竞品账号粉丝定向 (通过自定义人群包)

### 僵尸粉过滤
- 关注但 7 天内无互动的粉丝 → 标记为低质量
- 低质量粉丝占比 > 30% → 需要调整定向策略
