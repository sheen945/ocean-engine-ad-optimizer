# 巨量引擎后台网页操作导航

## 入口地址

| 平台 | 地址 | 用途 |
|------|------|------|
| 巨量引擎 | https://ad.oceanengine.com/ | 信息流广告管理 |
| 巨量广告 | https://ad.oceanengine.com/promotion/ | 推广管理 |
| 报表 | https://ad.oceanengine.com/report/ | 数据报表 |

## 一、查余额

### 方式1: 首页快速查看
1. 打开 `https://ad.oceanengine.com/`
2. 页面顶部右侧通常显示账户余额
3. 如不显示，找「账户信息」或「财务概览」区域

### 方式2: 财务中心
1. 导航到「账户」->「财务」->「资金管理」
2. 查看「现金余额」「赠款余额」「有效余额」
3. 截图记录: 全部三项

## 二、广告列表（推广管理）

### 查看活跃广告
1. 进入 `https://ad.oceanengine.com/promotion/`
2. 确认筛选条件: 状态 = 「投放中」
3. 列表显示字段: 广告名称、预算、状态、消耗、展现、点击、转化
4. 如需更多数据列 -> 点击「自定义列」添加「粉丝数」「互动数」等
5. **必须加上「成本保障」状态列** -> 自定义列里找「成本保障」或「赔付状态」

### 读成本保障状态（关停前必看）
计划列表里每条广告会显示赔付状态，关停决策完全依赖它：

| 显示状态 | 含义 | 该怎么做 |
|----------|------|---------|
| 成本保障生效中 | 在赔付期内且没违规操作 | 超成本也别停，跑满 3 天 |
| 成本保障确认中 | 系统正在核算（第 5-7 个自然日） | 什么都别动，等结果 |
| 成本保障已失效 | 改出价/定向超过 2 次，或作弊 | 赔付没了，按硬红线处理 |
| 成本保障已结束 | 转化数不够或没超 20% | 赔不到，按硬红线处理 |
| 赔付已到账 | 赠款已发放 | 看站内信确认金额，投入后续消耗 |

找不到这一列时，进「自定义列」搜索「保障」关键词勾选。

### 暂停广告
1. 在列表中找到目标广告行
2. 点击该行右侧的开关/暂停按钮 OR 勾选后批量暂停
3. 确认暂停操作

### 调整预算
1. 点击广告名称进入详情页
2. 找到「预算」区域 -> 点击编辑
3. 输入新预算 -> 保存

## 三、数据报表

### 查看日维度报表
1. 进入 `https://ad.oceanengine.com/report/`
2. 选择「广告计划报表」维度
3. 设置日期范围为昨日
4. 自定义指标列: 消耗、展现、点击、CTR、新增粉丝、点赞、评论、分享、CPM、CPC
5. 按消耗降序排列
6. 截图完整报表

### 计算关键指标
从报表中手动提取数据后计算:
- CPF = 消耗 / 新增粉丝
- CPE = 消耗 / (点赞 + 评论 + 分享)
- CTR = 点击 / 展现 x 100%

## 四、创建新广告

### 完整流程
1. 在推广管理页面点击「新建广告」按钮
2. 选择营销目标: 信息流推广 -> 账号关注（涨粉）/ 互动量（互动）
3. 填写广告组信息:
   - 广告组名称: [日期]-[类型]-[序号] 如 0605-干货-01
   - 日预算: 根据余额/新建数量计算
   - 投放时段: 全时段 或 根据时段分析倾斜
4. 设置定向:
   - 地域: 根据目标用户设置
   - 年龄: 18-40（泛）或细分
   - 性别: 不限 或 根据粉丝画像
   - 兴趣行为: 选 3-5 个精准兴趣词
   - 平台: 抖音 + 头条 + 西瓜
5. 设置出价:
   - 出价方式: oCPM
   - 优化目标: 关注 / 互动
   - 出价金额: 目标 CPF x 1.3
6. 上传素材:
   - 视频: 建议 9:16 竖屏，15-60 秒
   - 图片: 建议 9:16，3-5 张
   - 文案: 3-5 条不同角度
7. 提交审核 -> 等待通过

### 定向参考
精准吸粉定向组合:
- 兴趣词: 使用 `https://ad.oceanengine.com/tools/interest/` 查询相关兴趣词
- 排除已关注: 开启「排除已转化用户」
- 相似人群: 如有已转化粉丝 -> 开启「相似人群扩展」

## 五、常见操作路径总结

| 操作 | 导航路径 |
|------|---------|
| 看余额 | 首页 OR 账户 -> 财务 -> 资金管理 |
| 看广告 | 推广管理 -> 筛选「投放中」 |
| 看报表 | 报表 -> 广告计划报表 -> 昨日 |
| 关广告 | 推广管理 -> 找到广告 -> 暂停 |
| 建广告 | 推广管理 -> 新建广告 -> 走流程 |
| 改预算 | 广告详情 -> 预算 -> 编辑 |
| 查兴趣词 | 工具 -> 兴趣词查询 |

## 六、异常处理

### 弹出活动/公告弹窗
- 先关闭弹窗（点 X 或点「知道了」）
- 继续操作

### 出现验证码
- 停止操作
- 截图告知用户
- 等待用户完成验证后继续

### 页面加载慢
- 等待 5-10 秒
- 如仍不加载 -> 刷新页面

### 操作按钮不可点击
- 检查是否处于编辑状态
- 检查账户是否有权限
- 截图告知用户确认
